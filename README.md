# decompiling_transformers
Implementation of "Discovering Interpretable Algorithms by Decompiling Transformers to RASP" by Huang et al. (2026). Work completed as part of a Semester Project for ETH Zurich carried out under Ryan Cotterell's lab ([rycolab](https://rycolab.io/)) under the supervision of [Jiaoda Li](https://rycolab.io/authors/jiaoda/)
